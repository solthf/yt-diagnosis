# 영상 지표 진단실

YouTube 스튜디오 표를 붙여넣으면 노출 → 클릭 → 초반 유지 → 시청 유지 → 반응 → 구독 6단계로 나눠 병목 구간과 잘된 부분을 계산하는 무료 도구.

- 스튜디오 CSV 내보내기, 복사한 표, "항목 값" 목록 인식
- 롱폼·쇼츠별 판정 기준, 영상 길이별 평균 조회율 기준
- 채널·시리즈 카테고리 관리, 같은 채널·시리즈 3편 이상이면 평균 대비 비교
- 기록은 브라우저(localStorage)에만 저장, 서버 전송 없음. 기기 이동은 JSON 내보내기·불러오기

빌드 과정 없음. `index.html` 한 파일로 동작.
